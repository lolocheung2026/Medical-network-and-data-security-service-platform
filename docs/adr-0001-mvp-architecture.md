# ADR-0001：MVP 架构定案

日期：2026-09-23
状态：已接受（乐叔逐条确认）

## 背景

面向区县卫健委与中小医疗机构的公益性网络与数据安全服务平台。开发力量为乐叔 + LOLO，现有沙盘项目（Flask，553 行 app.py + engine/ + 18 场景）作为种子。

## 决策

1. **形态**：整体解决方案，Web/SaaS 入口，客户登录网站使用功能模块。
2. **数据红线**：原始医疗数据不出院。平台只接收两类输入：数据字典（schema 级）、自动脱密后的拓扑图。自动脱密沙盒是唯一数据入口，检测到原始数据（证件号/手机号成批出现）整体拒绝入库。
3. **功能与顺序**：① 数据分类分级（GB/T 39725 五级，首发）→ ② 攻防推演（纯仿真，沙盘引擎迁移，核心差异化）→ ③ 合规判断（二期，锚点：等保 2.0 + 医疗卫生机构网络安全管理办法 + GB/T 39725；不碰密评）。报告中心生成整改报告。
4. **模式**：科研院所公益免费 + 登录免责声明（参考性建议，不构成测评结论）。平台自身等保预算走科研专项经费。先影响力后收费。
5. **技术栈**：Flask 扩展（不换框架）；SQLAlchemy + SQLite 起步（ORM 预留 PostgreSQL）；多租户 = 表级 tenant_id 隔离；前端沿用沙盘 Canvas/SVG 拓扑体系。
6. **复用资产**：沙盘 engine/（攻击图、对抗画像、蒙特卡洛、工作流）、scenarios/（18 场景）、拓扑解析（file_parser/excel_import）、CVE+合规条文反哺库。
7. **责任边界**：上线前安排一次第三方渗透测试 + 代码审计作为信任状；脱密算法以「重识别攻击测试」为必测验收项。

## 当前骨架（v0.1）

- `app/auth`：登录 + 免责声明签署（session 认证，tenant_id 入会）
- `app/sandbox`：上传管道 + 脱密引擎 v1（PII 阻断 / IP 假名化 / 机构名盐哈希）
- `app/classify`：分类分级规则引擎 v1（关键词规则 → 五级定级 + 分布统计）
- `app/simulation`、`app/compliance`：占位，状态接口
- `app/reports`：本租户上传/脱密记录清单
- 种子账号 admin/admin123（仅开发期，上线前删除）

## 未决项

- 部署目标架构（上云方案）——按「未来上云」预留：ORM 无关、上传目录可配置、SECRET_KEY 走环境变量
- 规则库在线维护界面（当前硬编码，二期迁数据库）
