# ADR-0007：合规规则库扩展为 22 部法源

日期：2026-09-26
状态：已接受

## 背景

乐叔 2026-09-26 定案：规则库从三件套锚点（等保 2.0 / 管理办法 / GB/T 39725）
扩展为 22 部法律法规，覆盖网络、数据、个人信息、密码、卫生健康、人工智能、
数据跨境、人类遗传资源及重庆市地方立法。

## 决策

1. **法源表化**：新增 RegulationSource 表（code/name/short_name/category/active），
   效力层级五档：法律 5 · 行政法规 4 · 部门规章 4 · 规范性文件 7 · 地方性法规 2。
   ComplianceItem.anchor 从 3 枚举改为存法源代码（字符串关联，避免 FK 迁移成本）。
2. **页面按效力层级分组**：五档 → 组内按法源 → 检查项，替代原三锚点分组。
3. **检查项草案制**：27 条核心检查项（每部 1-2 条）为要点草案，页面与数据文件
   均标注"待审定"；正式条文由乐叔按官方发布文本逐条审定替换。
4. **数据文件拆分**：seed 数据独立 `app/compliance/seed_data.py`（纯数据，
   含 22 法源 + 27 检查项），routes.py 保持逻辑层 <300 行约束。
5. **旧数据迁移**：seed 幂等逻辑自动清理旧三锚点（mlps/measures/gb39725）
   检查项及关联评估记录。
6. **不碰密评不变**：密码法/商用密码条例检查项仅提示"咨询密评机构"。

## 影响

- `app/models.py`：+RegulationSource；ComplianceItem.anchor 语义扩展
- `app/compliance/routes.py`：seed/列表/report 重构（22 法源）
- `app/compliance/seed_data.py`（新增）：22 法源 + 27 检查项草案
- `app/templates/compliance.html`：五档层级分组渲染

## 冒烟证据（2026-09-26 实测）

- 合规页 200：五档分组渲染（5/4/4/7/2 = 22 部）
- 汇总接口：检查项总数 27、法源 22 部全量

## 未决项

- 27 条检查项草案待乐叔审定（正式条文 + 增补控制点，工作量估计半天+）
- 等保 2.0 三级控制点（8.1.x 系列）是否并入本清单或单独成组待定
- 法规修订跟踪机制（法源 active 开关已预留，订阅/提示机制未做）
